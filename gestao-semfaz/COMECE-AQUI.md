# Como iniciar o projeto no Claude Code

1. Exporte o prompt: abra o documento "Prompt Gestão SEMFAZ" no Claude, clique no nome do documento > Exportar > Markdown. Salve como `docs/PROMPT.md` nesta pasta.
2. Instale no computador: Node.js (versão LTS), Git, Docker Desktop, Supabase CLI e Claude Code.
3. Abra o terminal nesta pasta e rode `claude`.
4. Cole a mensagem abaixo:

> Leia o CLAUDE.md, o docs/PROMPT.md inteiro e os protótipos em docs/prototipos. Verifique as ferramentas instaladas (Node, Git, Docker, Supabase CLI). Depois, registre em docs/architecture.md a arquitetura, a estrutura de pastas, o modelo inicial do banco e o plano de segurança, e comece a Fase 1. Ao terminar a Fase 1, rode os testes, me apresente o relatório e pare.
